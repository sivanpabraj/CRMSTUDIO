# Critical Issues (P0)

### P0-1 — Local session forgery (missing `sig` accepted / auto-signed)
- **Why:** `Auth.getUser()` / `verifySessionSignature()` can accept or repair unsigned `sessionStorage` payloads.
- **Impact:** XSS or shared PC → become `studio_manager`.
- **Risk:** Full studio takeover (finance, users, export).
- **Fix:** Reject unsigned sessions; never auto-sign; move authority to Supabase JWT.
- **Effort:** S–M (1 focused PR + tests)

### P0-2 — Client is root of trust
- **Why:** Privileged CRM/finance writes happen in IndexedDB; Supabase is optional overlay.
- **Impact:** “Cloud security” docs oversell RLS; local writes bypass server authz.
- **Risk:** Multi-device SaaS trust model is false.
- **Fix:** Server RPCs for money + membership; local = cache only when online.
- **Effort:** L (architecture pivot)

### P0-3 — `send-sms` Edge: any authenticated user can send SMS
- **Why:** JWT check only; no `studio_members` / role / quota.
- **Impact:** Cost abuse, OTP flooding.
- **Fix:** Require manager membership + per-studio quotas + origin allowlist fail-closed.
- **Effort:** S

### P0-4 — OTP / invite secrets in client storage
- **Why:** Unified login stores plaintext OTP in `sessionStorage`; invite path can retain plaintext beside hash.
- **Impact:** XSS/DevTools → account takeover within TTL.
- **Fix:** Hash-only; drop plaintext immediately; prefer server-issued short tokens.
- **Effort:** S

### P0-5 — Snapshot sync last-write-wins wipe
- **Why:** Full JSON snapshot push/pull without optimistic concurrency.
- **Impact:** Two devices → silent data loss (contracts, banks, cheques).
- **Fix:** Version precondition; prefer entity sync; backup before pull; refuse stale push.
- **Effort:** M

### P0-6 — SMS API keys still usable from the browser
- **Why:** `js/sms.js` can call providers directly when proxy unset.
- **Impact:** Key exfil via XSS/export/backup.
- **Fix:** Production hard-require Edge proxy; strip keys from exports.
- **Effort:** S

# Architecture Review

**What works:** Offline-first IndexedDB for one photography studio; entity + snapshot hybrid; RLS write hardening in migrations 002/005/006; Edge SMS proxy *exists*.

**What fails for SaaS:** Browser owns authz; no org billing/seats; no real public API; snapshot LWW; dual shells; Vite copies static scripts instead of bundling app modules (`scripts/copy-static.mjs`).

**Enterprise alternative:**  
1) Supabase (or self-host) as **source of truth**  
2) Thin PWA cache  
3) Money/membership only via RPC  
4) One design system  
5) Bundled ES modules + TS  

**Self-host note:** Putting Auth on “your VPS” does **not** remove Google Cloud OAuth client setup. Self-host Supabase = same Provider toggle, on your instance.
