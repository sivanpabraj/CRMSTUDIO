# Studio AI Brain

## هدف
تصمیم‌یار مقید به داده واقعی CRMSTUDIO — نه چت عمومی.

## نقش‌ها
| نقش | خروجی |
|-----|--------|
| مدیر | مطالبات، چک، مراسم هفته، لید باز، خالص مالی + اعلان |
| پرسنل | «امروز با این پروژه شروع کن» + دستمزد باز |
| مشتری | مرحله کار + مانده دقیق |

## مالی
- بدهی قرارداد = مبلغ کل − پرداخت‌های ثبت‌شده (تراکنش deposit مرتبط یا deposit+paid)
- فیش/فاکتور از invoices و transactions
- پکیج قیمت از packages

## Gemini
- کلید فقط localStorage
- prompt سخت: خارج از استودیو → رد
- اعداد ترجیحاً از پاسخ محلی `_tryLocalAnswer`

## اعلان
`NotifyHub.notifyInApp` حداکثر یک‌بار در روز برای هر نوع هشدار (کلید در localStorage).
