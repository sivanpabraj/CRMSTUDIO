۱. وضعیت فعلی (تثبیت‌شده)
  • • کلاینت: IndexedDB بهینه + تاکسونومی ۴۲ کالکشن
  • • سینک توم‌استون (Tombstone): عدم بازگشت رکوردهای حذف‌شده
  • • حل باگ‌های بحرانی C1 و C2 (تقویم و بازیابی بکاپ)
  • • بک‌اند: سرور Node.js با ذخیره‌سازی ایزوله تننت‌ها و Gzip
۲. گام میان‌مدت پیشنهادی
  • • مهاجرت به SQLite با حالت WAL روی سرور
  • • ایندکس‌گذاری شماره موبایل و شناسه قرارداد در $O(1)$
  • • مهاجرت ۲۴ مجموعه حساس (حضورغیاب و حقوق) به سینک تفاضلی
  • • اعمال مهاجرت RLS شماره ۰۰۸ برای مسدودسازی نشت مالی
۳. چشم‌انداز سطح سازمانی
  • • PostgreSQL چندمستأجری با تفکیک اسکیمای استودیوها
  • • صف پیام BullMQ با پشتیبان Redis برای پیامک و بله
  • • باندل یکپارچه Vite و ماژول‌های ES با Code Splitting
  • • ماژول هوش مصنوعی تحلیلی با ارزیابی نرخ سوددهی پروژه‌ها
